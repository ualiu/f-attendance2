# Market Insights & Positioning

## Target Market

### Primary Audience
- **Company size:** 50-200 employees
- **Industries:** Manufacturing, warehouses, production facilities, shift-based operations
- **Pain point:** Production managers drowning in voicemails instead of actually managing
- **Decision maker:** Operations manager, HR, production supervisor

### User Personas
| Persona | Behavior | What They Need |
|---------|----------|----------------|
| Floor worker | Texts casually, typos, slang | Zero friction - just text and done |
| Older worker (2%) | Resistant to new tech | Voicemail fallback option |
| Supervisor | Drowning in voicemails | Dashboard, not phone tag |
| Manager | Needs coverage visibility | Real-time attendance view |

---

## Validated Insights (Real User Feedback)

### The 30-Second Rule
> "If operators need more than 30 seconds they won't use it"

**Implication:** Every interaction must be completable in under 30 seconds. No complex flows.

### SMS Beats Forms
> "SMS is honestly smarter, less friction than a form even"

Even users who successfully implemented Google Forms acknowledge SMS is lower friction because:
- No link to click
- No app to open
- No dropdowns to navigate
- Text like they already do

### The 98/2 Strategy
> "98/2 split with voicemail backup is exactly the right call - no point fighting the 2%"

**Strategy:** Design for the 98%, accommodate the 2%. Don't redesign the whole system for edge cases.

### The Real Problem We Solve
> "Voicemail thing drove me insane tbh, production manager was always catching up instead of actually managing"

**Core value prop:** Give production managers their time back. Stop playing phone tag.

## Feature Prioritization Framework

When evaluating features, score against these criteria:

### Must Support
- [ ] Completable in <30 seconds
- [ ] Works via SMS (no app required)
- [ ] Handles messy/informal input
- [ ] Reduces manager phone tag time

### Should Support
- [ ] Provides dashboard visibility
- [ ] Surfaces patterns (points, trends)
- [ ] Multi-tenant ready
- [ ] Fallback for the 2% (voicemail, manual entry)

### Avoid
- Complex multi-step flows
- Features requiring training
- App-only functionality
- Rigid structured input

- Selecting from dropdowns
- Structured answers only
- Re-submission on errors

We handle:

- Typos, slang, emojis ✓
- Follow-up questions if info missing ✓
